# projectin_rpg — Project IN ダンジョン & 大型ボスレイド

Qbox / ox_inventory / oxmysql / ox_lib 環境向けの、期間限定ダンジョン・大型ボスレイドリソースです。
通常の街RPには影響しないよう、ロール効果・戦闘・戦利品はすべて **アクティブなダンジョン/レイド内だけ** で動作します。

---

## 1. 動作環境 / 依存

| リソース | 用途 |
|---|---|
| `qbx_core` | キャラクター (citizenid)・ログイン/ログアウトイベント |
| `ox_inventory` | 入場中の通常所持品の預かり(スタッシュ)、貸与武器、持ち出し防止フック |
| `oxmysql` | 永続化 (既存DBに `rpg_` で始まるテーブルを追加。既存テーブルは変更しません) |
| `ox_lib` | コールバック・アニメ/パーティクル読み込み (メニューUIは使いません。UIは全て独自NUI) |

OneSync (Infinity 推奨) が必須です (サーバー側でのPed生成・ルーティングバケット・座標取得を使用)。

> このリポジトリには qbx_core / ox_inventory / oxmysql 本体が含まれていなかったため、
> それぞれの **公開APIに合わせて実装** しています (詳しくは「制限事項」)。

## 2. インストール

1. `projectin_rpg` フォルダを `resources` に配置
2. SQL を実行 (起動時にも `CREATE TABLE IF NOT EXISTS` で自動作成されます)
   ```
   sql/projectin_rpg.sql
   ```
3. `server.cfg` (依存の **後** に ensure)
   ```
   ensure oxmysql
   ensure ox_lib
   ensure qbx_core
   ensure ox_inventory
   ensure projectin_rpg

   # 管理者権限 (group.admin にRPG管理を許可)
   add_ace group.admin projectin_rpg.admin allow
   ```
4. 初回起動時に、初期ダンジョン「採石場の魔窟」と初期レイド「チリアド山頂決戦」、敵/定義テンプレートがDBへ投入されます。

## 3. プレイヤー向け

| 操作 | 内容 |
|---|---|
| `/rpg` | メニュー (初回はロール選択 → ホーム/イベント/パーティー/RPGインベントリ) |
| イベント地点で `E` | ダンジョン入場 / レイド参加登録 |
| ダンジョン内 `E` | ドロップを拾う / 目標オブジェクトを長押しで破壊 |
| 魔導士 `1`〜`4` | ヒール / パワーブースト / サンクチュアリ(範囲回復) / リザレクション(蘇生) |
| 魔導士 `G` | スキル対象の切り替え (自動選択 ↔ パーティーメンバー) |
| 武器 | 入場時に貸与される武器を ox_inventory のホットバー/インベントリから装備 |

キーはFiveMの「設定 → キー設定 → FiveM」で変更できます。

### ロール (キャラクターごとに一度だけ選択 / 変更は管理者のみ)

| ロール | 効果 (ダンジョン/レイド内のみ) |
|---|---|
| タンク | HP 1.5倍 / 与ダメージ 0.8倍 |
| アタッカー | HP 0.8倍 / 与ダメージ 1.5倍 |
| 荷物持ち | RPGインベントリのスロット数・重量上限 2倍 |
| 魔導士 | MPとクールダウンで回復・バフ・蘇生。攻撃不可 |

### RPGインベントリ
- `/rpg → RPGインベントリ` からいつでも閲覧・並べ替え・破棄ができます。
- 中身は **ox_inventoryのアイテムではありません** (専用テーブル `rpg_characters.inventory`)。街のインベントリ・ショップ・経済には一切出入りしません。
- 回復薬などの消耗品はダンジョン内でのみ使用可能。
- 容量不足で受け取れなかった報酬は「受取箱」に保管され、空きができたら受け取れます。

### 入場〜帰還の流れ
1. 入場時、通常の所持品は鍵付きスタッシュ `rpghold_<citizenid>` に預けられ、ロールに応じた貸与装備が支給されます。体力・アーマー・帰還位置も記録されます。
2. パーティーごとに専用のルーティングバケット(別空間)で攻略。
3. クリア/全滅/時間切れ/離脱/管理者終了のいずれでも、貸与品を回収 → 預かり品を返却 → 体力・アーマー・位置・バケットを復元。
4. 切断・キャラ切替の場合は、そのキャラで **次回ログインした時** に自動で返却・帰還します。
5. リソース停止時はその場で即座に返却・帰還させます。

## 4. 管理者向け

`/rpgadmin` または `/rpg → 管理` タブ。全ての管理操作はサーバー側でACE権限を再確認し、`rpg_audit_log` に記録されます。

### イベント予約 (日本時間)
- 公開済みのダンジョン/レイドを選び、**場所の表示名** (例: `8012番地`)、開始/終了日時を `YYYY-MM-DD HH:MM` で入力します。`24:00` も使えます。
- 「今 / +30分 / 本日24時」などのクイックボタンあり。
- 「告知をプレビュー」で実際の告知文を確認できます。
  - ダンジョン例: 「8012番地でダンジョン発生！本日24時まで！」
  - レイド例: 「3001番地で大型ボスレイド発生！開始まで30分！」
- ダンジョン: 開始〜終了の間、何度でもパーティーで入場可能。終了1時間前にリマインド告知。
- レイド: 告知(既定は開始30分前)から開始までが参加登録期間。30/10/5/1分前にリマインド。開始時刻に集合地点付近にいる登録者で一斉開始 (定員まで)。
- 一覧から「再告知 / 今すぐ終了 / 中止」が可能。

### ロール管理
- オンラインプレイヤー一覧、またはCitizenIDで検索(オフライン可)して変更/リセット。
- コンソール: `rpgrole <citizenid> <tank|attacker|porter|mage|reset>`
- ダンジョン参加中のキャラは変更できません。

### 稼働中インスタンス / ログ
- 実行中の全インスタンス(メンバー・ウェーブ・残り時間・バケット)を確認し、強制終了できます。

## 5. ゲーム内エディター (コード不要)

`管理 → ダンジョンエディター` から、新規作成 / テンプレートから作成 / 編集 / 複製 / 公開 / アーカイブ。

| セクション | 内容 |
|---|---|
| 基本情報 | 名前・種類・人数・制限時間・説明・IPL(MLO/インテリア) |
| 配置・境界 | 入口(街側)・開始地点・帰還地点・境界(中心/半径/高さ) |
| 敵プリセット | モデル・HP・武器・命中率・アーマー・軽減率・ドロップ表。敵テンプレートの保存/読込 |
| スポーン地点 | 敵の出現地点 (配置モード/現在地) |
| プロップ | 小道具の設置 (破壊目標にも使用) |
| ウェーブ | 目標(全滅/指定数/破壊/生存/ボス)・待機秒・メッセージ・敵グループ(出現地点・再出現) |
| ボス | ボスプリセット・出現地点・フェーズ(HP%しきい値/被ダメ倍率/命中率/範囲攻撃/増援) |
| 報酬 | クリア報酬の抽選表 |
| 告知文 | テンプレート編集とプレビュー |
| 検証・テスト・公開 | 公開可否の検証、**非公開テストプレイ**(任意ロール・報酬なし)、公開 |

- **配置モード**: カメラの照準先に配置。マウスホイールで向き、Shiftで微調整、`E`/左クリックで決定、`G`で現在地、`Backspace`/右クリックで取消。プロップ/Pedは半透明のゴーストで確認できます。
- **ワールドにプレビュー**: 編集中の地点・境界を自分の画面だけに表示。
- 下書きは未完成でも保存できます(警告を表示)。公開・テストはサーバー側のスキーマ検証を通過したものだけ。
- 公開すると、予約済み/開催中イベントにも新しい版が反映されます (実行中のインスタンスは開始時の内容のまま)。

### MLO対応
座標ベースなので、MLO内部に開始地点・スポーン・境界を置けばそのまま使えます。IPLが必要な場合は基本情報の「読み込むIPL」に指定してください(入場者のクライアントでのみ読み込み、退出時に解除)。

## 6. セキュリティ / 不正対策 (サーバー側検証)

- **ダメージ**: 敵HPはサーバーのみが管理。命中報告ごとに「参加中か / 攻撃可能ロールか / ロールの貸与武器か / 実際に構えている武器と一致するか / 武器ごとの発射間隔 / 射程 / 敵が同じインスタンスに属するか」を検証し、倍率計算もサーバーで実施。
- **スキル**: MP・クールダウン・射程(サーバー座標)・対象(同じインスタンス/生存/ダウン)を検証。
- **ドロップ/報酬**: メンバーごとの個人ドロップ。取得は所有者・距離・状態を検証し、`rpg_claims` の UNIQUE キー付きトランザクションで付与 → **二重取得/二重付与は不可能**。
- **インベントリ隔離**: ox_inventory フックで、入場中の受け渡し・ドロップ・スタッシュ・ショップ・クラフト・通常アイテム使用を禁止。貸与品はどこにいても他のインベントリへ移動不可。預かりスタッシュはクライアントから開けません。
- **エディター**: 送信データはサーバーで型・範囲・件数・参照整合性をチェックして再構築(未知のフィールドは破棄)。
- **境界**: クライアントの警告に加え、サーバーでも定期的に位置を確認して範囲外なら開始地点へ戻します。

## 8. 実機での確認手順 (チェックリスト)

テスト用サーバーで、管理者1名 + 一般プレイヤー1〜2名で実施してください。

1. **起動**: コンソールに `[projectin_rpg] 起動しました` が出る / DBに `rpg_` テーブルが作成され、`rpg_definitions` に2件。
2. **ロール**: 一般プレイヤーで `/rpg` → ロール選択 → 再度 `/rpg` で選択画面が出ないこと。管理画面からリセット→再選択できること。
3. **座標調整**: 管理者で `管理 → エディター → 採石場の魔窟 → 配置・境界` を開き「ワールドにプレビュー」。入口・開始地点・スポーン・プロップが地面上の妥当な位置にあるか確認し、必要なら配置モードで修正 → 公開。チリアド山頂決戦も同様。
4. **テストプレイ**: エディターの「検証・テスト・公開」からロールを選んでテスト → 敵が出現し、こちらを攻撃してくること / 敵頭上にHPバー / 命中でHPが減ること / ウェーブが進行すること / 報酬が付与されないこと。
5. **イベント予約**: 開始=今、終了=本日24時で予約 → 全員に「〇〇でダンジョン発生！本日24時まで！」が表示され、マップにブリップ。
6. **入場**: パーティーを組み入口で `E` → 入場。入場前に持っていた現金/武器/アイテムがox_inventoryから消え、貸与武器だけになること。
7. **隔離**: 入場中に別プレイヤー(街)から見えないこと / ox_inventory で地面に捨てる・他人に渡すが拒否されること。
8. **ロール効果**: タンクとアタッカーで体力バーの最大値が異なる / 魔導士は射撃・近接ができない / 魔導士の1〜4キーで回復・バフ・蘇生 / 荷物持ちのRPGインベントリが60スロットになる(街では30)。
9. **ダウン**: わざと倒される → 「戦闘不能」表示、医療スクリプトの死亡画面が出ないこと → 魔導士のリザレクションかウェーブクリアで復活。
10. **クリア**: ボス撃破 → 結果画面 → 帰還で入場前の位置・体力・アーマー・所持品が完全に戻ること、`/rpg → RPGインベントリ` に報酬。
11. **切断**: 入場中にゲームを終了 → 再接続してキャラ選択 → 入口付近へ戻り、所持品が戻ること。
12. **再起動**: 入場中に `restart projectin_rpg` → その場で所持品が戻り街へ帰還すること。
13. **レイド**: 開始10分後で予約 → 登録 → 開始時刻に集合地点の登録者が一斉に転送されること、リマインド告知。
14. **二重付与**: `rpg_claims` にrun_idごとの請求キーが1件ずつ記録されていること。

## 9. 制限事項・注意点 (正直に)

- **実機未検証**: 上記の通り、ゲーム内での動作は未確認です。特に次の点は環境依存のため要確認です。
  - Qboxのイベント名 `QBCore:Server:PlayerLoaded` / `qbx_core:server:playerLoggedOut` / `QBCore:Client:OnPlayerLoaded`、ステートバッグ `isLoggedIn`。
  - ox_inventory フック (`swapItems` / `openInventory` / `usingItem` / `buyItem` / `craftItem`) のペイロード形式はバージョンにより差があります。
  - 医療スクリプト連携: ダンジョン内は独自のダウン処理でネイティブ死亡を防いでいますが、爆発などで万一死亡した場合は `Config.Medical.reviveClientEvent` (既定 `qbx_medical:client:playerRevived`) を呼びます。お使いの医療リソースに合わせて変更してください。被弾時の負傷/出血などの演出は医療スクリプト側の仕様に依存します。
- **初期座標は概算**: GTA標準マップの既存地点(デイビス・クォーツ採石場、チリアド山頂)を使っていますが、正確な座標は実機で確認していません。Z座標はクライアントで地面にスナップしますが、エディターで調整してください。
- **敵モデル**: `u_m_y_juggernaut_01` は比較的新しいゲームビルドで追加されたモデルです。出現しない場合はエディターで `s_m_y_blackops_03` 等に変更してください (モデル名欄でゲーム内存在チェックが出ます)。
- **敵→プレイヤーのダメージ**: 敵の攻撃はGTA標準AIによるクライアント側ダメージです (プレイヤー→敵はサーバー権威)。ゴッドモードのチート使用者は倒れない可能性があります。ボスの範囲攻撃の判定はサーバーで行いますが、ダメージの適用は対象クライアントです。
- **ヘッドショット判定**: クライアント申告 (倍率1.3、連射間隔・射程はサーバーで制限)。
- **所持品の永続化タイミング**: 預かり品は ox_inventory のスタッシュに入るため、保存タイミングは ox_inventory に依存します。通常の再起動・切断では問題ありませんが、サーバーの **強制クラッシュ** 直前に入場した場合のデータは ox_inventory の保存間隔の影響を受けます。サーバー再起動は通常手順で行ってください。
- **レイド中の再起動**: 実行中のレイドは継続できず終了扱いになります (所持品は返却)。
- **パーティー**: メモリ上で管理しているため、リソース再起動で解散します。
- **場所名「XXX番地」**: 告知の場所名は管理者入力です (ポスタルリソースからの自動取得はしていません)。
- **敵生成の一瞬**: サーバー生成Pedは生成直後にバケットへ移動するため、ごく短時間だけ通常空間に存在します(街側から見えることはほぼありません)。
- **ダウン中**: 観戦カメラはありません (その場で倒れたまま待機)。
- 回復量の統計は「実際に回復した量」の概算です。

## 11. カスタマイズ

- ロール倍率・魔導士スキル・武器ダメージ: `config.lua`
- RPGアイテムの追加: `shared/items.lua` (追加後はエディターのドロップ/報酬で選択可能)
- 告知テンプレートの既定文: `Config.DefaultAnnouncements`
- ルーティングバケット範囲 (他リソースと重複しないように): `Config.Instance.bucketStart / bucketMax`
